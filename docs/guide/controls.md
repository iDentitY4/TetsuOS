# Controls

The RG35XX SP has a D-pad, A, B, X and Y, L1, R1, L2 and R2, Select, Start, a Menu button,
the volume buttons and the power button. The face buttons are laid out X top, Y left,
A right and B bottom.

## In the menus

| Button | What it does |
| --- | --- |
| D-pad | Move. Hold to repeat |
| Left / Right | In a list: page up and down |
| A | Open, start, choose |
| B | Back |
| X | Search all games |
| Y | A game's details: play time, collections, screenshots, hide or delete |
| Select | Star or unstar a game (FAVORITES) |
| L1 / R1 | In a list sorted by name: jump to the previous or next letter |
| Start | Open or close Settings, from anywhere |
| Volume | Change the volume, with a sign at the top |

Settings that can't be undone, such as deleting a game or all covers, need A twice in a
row. Any other button calls it off.

## In a game

| Button | What it does |
| --- | --- |
| Menu (tap) | Pause and open the [in-game menu](./playing#the-in-game-menu) |
| Menu + Start | Leave the game straight away, keeping your place |
| Menu + Select | Open the [game switcher](./playing#switching-games) |
| R2 (hold) | Fast-forward, shown as `>>` in the corner (not on the PlayStation) |
| Volume | Change the volume |
| Select | On WonderSwan: rotate the picture for vertical games |

Every other button goes to the game. You can change what each button does, and add turbo,
for a console or a single game: see [Remapping and turbo](./playing#remapping-and-turbo).

The Menu button and the D-pad can't be remapped, so the menu always stays in reach.

## Power and lid

| Action | What happens |
| --- | --- |
| Power button (short press) | Power off, with a shutdown screen. A game in progress resumes at the next start |
| Power button, while off | Power on |
| Close the lid | Sleep. A game saves its place first. Opening the lid wakes the device |
| Plug in USB while off | The device starts to a charging screen. The power button goes on to the menus |

See [Power and battery](./power-and-battery) for sleep timers and power-off after sleep.

## Bluetooth controllers

A paired controller acts as the device's own buttons, in the menus and in games. Its
D-pad hat and left stick work as the D-pad. See [Bluetooth](./bluetooth).

## Testing the buttons

**Settings > SYSTEM > BUTTON TEST** shows each control as you press it: filled while held,
outlined once seen, with the last press named below.
